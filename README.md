## 🛏️ Featured project — Room No. 001

<div align="center">

### A little room. A lot of ideas.

</div>

A personal website inspired by the feeling of stepping into a cozy digital bedroom.

Built with a real-time 3D scene, the experience lets visitors scroll through a virtual room while the camera moves through the space.

Think interactive storytelling meets a tiny world on the internet.

**The mission:**

- 🎨 Create a stylized bedroom inspired by Blender renders.
- 🧊 Build the environment using React Three Fiber and Three.js.
- 🎥 Connect scrolling to camera movement.
- 💡 Experiment with lighting, materials, and atmosphere.
- 🚀 Deploy the experience with Vercel.
